# Narrata

A native iOS audiobook player for [Audiobookshelf](https://www.audiobookshelf.org) servers you
host yourself.

Narrata is an independent app. It is not affiliated with or endorsed by the Audiobookshelf
project.

- [Support](https://leperchaun.github.io/narrata/support)
- [Privacy Policy](https://leperchaun.github.io/narrata/privacy)

This repository hosts the app's support and privacy pages. The app source is not published here.

## What it does

Streams and downloads audiobooks from your own Audiobookshelf server. Chapters, playback speed,
sleep timer, bookmarks, and listening stats. A Continue Listening Home Screen widget and a Live
Activity while a book plays. Lock screen controls, AirPlay, and offline playback with progress
that syncs back when you reconnect.

Requires iOS 26 or later and an Audiobookshelf server (v2.26+ recommended).
